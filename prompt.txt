Design a modern, friendly web app UI called “Logic Assistant“ for middle-school users + teachers. The app has TWO clearly separated modes with a top-level toggle (tabs or segmented control): (1) Text Analysis and (2) Quiz Mode. Create Desktop (1440w), Tablet (834w), and Mobile (390w) frames using Auto Layout, components, and variants.

Brand + style
- Tone: approachable, smart, not childish. Clear visual hierarchy.
- Style: clean cards, soft shadows, rounded corners, subtle gradients.
- Accessibility: WCAG AA contrast, large tap targets, readable type.
- Suggested palette: Primary green (#4CAF50) + darker hover (#3D8B41), neutral background (#F7F9FA), card white, borders light gray.
- Typography: modern sans (Inter or similar). Headings bold, body regular.

Global layout
- Header: “Logic Assistant“ + mode toggle (Text Analysis | Quiz Mode). Optional short tagline.
- Content area: centered container (max ~900px), card-based layout.
- Global states: loading spinner, inline error banner, empty-state illustrations, success toast.
- Include “Example“ quick-fill buttons for both modes.

MODE 1: Text Analysis (matches backend output)
Input
- Large textarea labeled “Paste text to analyze“ (6-10 rows), placeholder guidance.
- Primary button: “Analyze“.
- Secondary actions: “Clear“, “Paste“, “Use Sample“.
Results (render as friendly UI, not raw JSON by default)
- Top summary card: “Summary“ (single paragraph).
- Section cards with counts + list items:
  1) “Contradictions“ list: each item shows Reason + two snippet chips labeled “A“ and “B“.
  2) “Topic Shifts“ list: From → To + snippet.
  3) “Repeating Claims“ list: Subject, Base claim, Count, and “Variations“ collapsible rows.
- Add a “View JSON“ toggle (collapsed by default) with “Copy JSON“ button.
- Empty states when no contradictions/topic shifts/repetition found.

MODE 2: Quiz Mode (select box interaction)
Input
- A select dropdown labeled “What do you want help with?“ (required).
- Options (exact labels): Spotting contradictions, Avoiding repetition, Staying on topic, Using evidence, Timeline/order of events, Something else
- If “Something else“ chosen: reveal a small text input for custom issue.
- Primary button: “Generate Quiz“.
- Helper text: “You’ll get ~10 practice questions.“

Quiz results (matches backend schema)
- Teacher summary banner: “Summary for teacher“ (1-2 lines).
- Questions list as cards or accordion:
  - Show: Q#, question text, type badge (MCQ / True-False / Short), difficulty badge, skill tag.
  - For MCQ: show choices A-D.
  - Add a “Practice Mode“ interaction: “Start quiz“ button that steps through questions one-by-one with progress (e.g., 3/10), answer selection, “Check answer“, then reveal correct answer + one-sentence explanation.
  - Optional: “Show source snippets“ collapsible area.
- Provide “Export“ actions: Copy JSON, Download (placeholder), Print-friendly toggle.

Components to create (with variants)
- Buttons (primary/secondary/ghost, hover/disabled/loading)
- Tabs/segmented control (selected/unselected)
- Select dropdown + options + error state
- Textarea/input fields (default/focus/error)
- Result list items (contradiction/topic shift/repeat claim)
- Question card (mcq/true-false/short) + badges (difficulty/skill)

Microcopy + edge cases
- Error examples: “Text is required“, “User issue is required“, “Something went wrong—try again.“
- Loading text: “Analyzing“ / “Generating quiz“
- Empty results: “No contradictions found in this text.“

Deliverables
- One combined “Main“ screen with mode toggle (preferred) plus optional separate screens for quiz practice flow (Start → Answer → Review).
- Use consistent spacing scale (8px), clear grid, and responsive behavior (stack cards on mobile).
